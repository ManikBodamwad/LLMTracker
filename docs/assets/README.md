# Demo Assets

Place demo GIF and screenshots here.

## Required files:
- `terminal_demo.gif` — Screen recording of `tracker.report()` terminal output
- `html_dashboard.png` — Screenshot of the generated HTML report

## How to record terminal_demo.gif:
1. Install asciinema: `pip install asciinema`
2. Run: `asciinema rec terminal_demo.gif`
3. Execute: `python examples/quickstart.py`
4. Stop recording: `exit`
5. Convert to GIF if needed: use https://github.com/asciinema/agg

## How to capture html_dashboard.png:
1. Run: `python examples/quickstart.py`
2. Open `demo_report.html` in browser
3. Screenshot the full page
4. Save as `html_dashboard.png`
